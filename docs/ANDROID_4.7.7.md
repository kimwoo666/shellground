# Android 4.7.7

Android 학습 화면과 Linux 실습 시작을 개선한다. 기준 소스는 4.7.6의 NAS 동기화와 학습 자료를 포함한다.

## 화면과 진도

- 앱 아이콘으로 실행하면 Linux가 열린다. Python 전용 경량 빌드와 Android 8 이하는 Python 화면을 유지한다.
- 과정 순서는 Linux → Python → Conda·pip → Jupyter다. 두 화면에서 같은 과정 선택 줄을 사용한다.
- 단원 목록은 강의에 들어 있는 순서를 유지한다. 활용 문제를 푸는 중에도 목록의 단원 이름을 볼 수 있다.
- 단원 상태는 미시작·진행 중·완료로 표시하고, 예시·활용 1·활용 2의 완료 여부를 각각 표시한다. 설명을 읽은 위치를 문제 통과로 계산하지 않는다.
- 화면이 넓으면 설명과 작업 영역을 나란히 표시한다. 키보드가 열리면 제목·과정 선택을 접어 입력 공간과 하단 버튼을 확보한다.
- 입력 코드나 실행 중인 실습이 있는 상태에서 과목을 바꾸면 임시 작업이 종료됨을 확인한다. 완료 기록은 기존 저장 형식을 사용한다.

## Linux 시작

앱을 여는 동안 Linux를 미리 준비한다. 설명 읽기와 단원 선택은 계속 사용할 수 있으며, 준비 취소도 가능하다. 문제 준비 도중 다른 단원을 선택하면 현재 요청이 끝난 뒤 가장 최근에 선택한 단원만 준비한다.

최초 설치 또는 앱 업데이트 후에는 실습 이미지의 SHA-256을 검사한다. 이후에는 앱 전용 읽기 전용 파일의 경로·크기·inode·수정 시각·상태 변경 시각·권한·예상 해시와 앱 업데이트 시각이 같을 때 검사 기록을 재사용한다. 파일이나 명세가 바뀌면 해시를 다시 검사하며, 부팅 오류가 발생해도 검사 기록을 무효화한다. 외부 저장소 파일에는 이 기록을 적용하지 않는다.

변경된 채점 자료는 압축해 파일당 한 번 전송한다. 이전에는 원문 4KB마다 Python 프로세스를 실행했다. 게스트에서 압축 해제 크기와 SHA-256을 확인한 뒤 임시 파일을 원자적으로 교체하며, 같은 자료는 재전송하지 않는다.

과목 변경이나 취소 직후에는 이전 Linux 프로세스의 종료를 기다렸다가 다시 연결한다. 작업 응답은 원래 요청한 화면으로 보내며, 이전 화면의 오류가 새 화면을 닫지 않도록 한다. 앱을 벗어나면 VM 종료와 임시 작업 정리는 유지한다.

이 변경은 부팅 자체를 없애지 않는다. 최초 이미지 설치와 Android의 실제 ARM 기기 성능은 별도로 측정해야 한다.

## Java 변경용 빌드

Python·게스트·강의 자료를 바꾸지 않은 경우에만 다음 경로를 사용할 수 있다.

```text
gradle :app:assembleDebug :app:assembleDebugAndroidTest -PlinuxRuntime=true -PbundleLinuxPack=true -PreuseJavaPayload=/private/Shellground-4.7.6-Android.apk
```

`SHELLGROUND_BUILD_PYTHON`에는 Python 3.13 실행 파일, `SHELLGROUND_ANDROID_KEYSTORE`에는 기존 키의 비공개 경로를 지정할 수 있다. 지정하지 않으면 기존 프로젝트 키 경로를 사용한다. 서명 키는 저장소에 추가하지 않는다.

`reuse_java_payload.py`는 고정된 4.7.6 APK 해시와 Python·강의 소스 지문을 확인한다. 자료나 Python 의존성 설정이 다르면 재사용 빌드를 거부한다. 기존 DEX·리소스·서명을 복사하지 않으며 Java·리소스·매니페스트·APK 서명은 Gradle이 새로 만든다. Python 등을 변경할 때는 기존 전체 빌드 경로를 사용한다.

## 확인 범위

- 원본 인증서 SHA-256: `d3a7e87f11d75837f3b95523c887bbbef0b08d690a0ebee5876847bf85814578`.
- 4.7.6 위에 versionCode 477 업데이트 설치 및 기존 완료 기록 보존 확인.
- 실습·Python·네이티브 파일 158개가 4.7.6과 동일함을 CRC와 크기로 확인.
- 로컬 Android 회귀 검사 10개: 진도 판정, 과정 전환 보류, 단원 순서, 분할 배치, 실제 압축 설치 스크립트, 이미지 검사 기록의 무효화.
- Android 36.1 x86_64 에뮬레이터의 360×640dp 세로 화면에서 UI·키보드·입력·진도 검사 15개 통과. 실제 게스트 실습 1개는 별도 선택 검사다.
- 사용자 관점 검토 에이전트가 실제 세로 화면 캡처 4개를 확인했고, 중대한 가림·읽기·완료 구별 문제를 발견하지 않았다.
- 실제 ARM 휴대폰의 성능·발열은 미검증이다. 전체 강의 실습을 재실행한 결과가 아니다.
