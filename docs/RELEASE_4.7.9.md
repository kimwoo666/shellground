# Shellground 4.7.9 — Windows · Linux

- NAS 진도를 불러온 뒤 다른 분야의 단원으로 이어갈 때 왼쪽 목록이 이전 분야의 아래쪽에 머무르던 문제를 수정했다. 창 배치가 끝난 뒤 선택한 단원이 화면에 보이도록 다시 맞춘다.
- 시작 모드 선택 화면의 완료 숫자는 이 기기에 저장된 기록이며, NAS 진도는 모드 선택 후 불러온다는 점을 명시했다.
- 4.7.8의 종합 복습 완료·마지막 복습 위치 NAS 동기화와 scikit-learn 9문제 추가를 포함한다.
- Windows 설치는 기존 바탕화면·시작 메뉴·작업표시줄의 Shellground 아이콘을 새 실행 파일로 갱신한다.

Windows: `Shellground-Windows-Setup.exe`  
Linux: `Shellground-Linux-Setup.run`  
Android는 기존 4.7.7 릴리스를 이용한다.
