# NAS 학습 진도 동기화

NAS에는 완료한 단원·소단계, 활용 문제와 퀴즈 기록, 기억노트만 저장합니다.
실습 VM, 터미널 기록, 입력한 코드, NAS 비밀번호, 앱 표시 설정은 전송하지 않습니다.

## 사용하기

1. NAS에 Shellground 전용 폴더를 준비합니다. 다른 개인과 진도를 섞지 않도록 본인만 접근할 수 있는 공유 권한을 사용하세요.
2. 첫 기기의 **진도 동기화 → NAS 연결 설정**에서 그 폴더를 선택합니다. 빈 폴더일 때만 새 프로필 만들기를 선택합니다.
3. 다른 기기에서도 **같은 NAS 폴더**를 선택합니다. 기존 프로필에는 새 프로필을 만들지 않습니다.
4. Windows는 연결된 공유 폴더 또는 `\\NAS\공유\Shellground\progress-v1` 형태의 UNC 경로를 사용할 수 있습니다. NAS 로그인은 운영체제의 기존 연결을 사용합니다. Linux는 연결된 폴더나 기존 rclone 연결을 사용할 수 있습니다.
5. Android는 학습 메뉴 **NAS 진도 동기화**에서 NAS 주소, 공유 이름, 공유 안의 하위 폴더, 계정을 입력합니다. Windows의 `\\nas.local\study\Shellground\progress-v1`에 해당한다면 주소는 `nas.local`, 공유는 `study`, 하위 폴더는 `Shellground/progress-v1`입니다. 실제 개인 주소나 계정은 이 문서·배포본에 포함하지 않습니다. 처음 연결할 프로필은 PC에서 만드세요.

Android는 별도 PC 없이 SMB 2/3으로 NAS에 직접 연결합니다. 같은 Wi-Fi 또는 본인 VPN을 사용하고 SMB 포트를 인터넷에 개방하지 마세요. 계정·비밀번호와 연결 정보는 Android Keystore의 AES-GCM 키로 암호화하여 앱 전용 저장소에만 저장하며, 백업·진도 전송 대상에서 제외합니다. 연결 해제는 로컬 로그인 설정만 지우며 이미 완료한 학습 기록은 유지합니다.

앱을 열 때 NAS 진도를 먼저 읽습니다. 학습 중 변경은 백그라운드에서 저장하며 **F9**로 즉시 저장을 요청할 수 있습니다. 다른 기기로 옮기기 전 상태 표시가 **NAS 저장 완료**인지 확인하세요. 다른 기기에서 들어온 변경은 다음 앱 시작에 적용하므로 현재 풀던 문제나 입력창이 갑자기 바뀌지 않습니다.

인터넷/NAS가 없으면 로컬 진도로 학습합니다. PC의 실패 재시도 간격은 30초입니다. Android는 변경 기록을 모아 전송하고 연결 실패 뒤에는 다음 저장·수동 저장·앱 재시작에서 다시 시도하며, 배경에서 계속 접속하지 않습니다. 종료 시 NAS 연결을 무한정 기다리지 않습니다. NAS에 아직 저장하지 못한 최신 진도는 해당 기기에 남으므로 그 기기에서 다시 연결해야 전송됩니다.

## 기록 보호

- 각 기기는 자기 스냅샷 하나만 기록합니다. 서로의 파일을 덮어쓰지 않습니다.
- 완료 목록과 확인한 소단계는 합집합으로 합쳐 이미 획득한 완료가 사라지지 않습니다. 이 기능은 완료 기록 초기화를 다른 기기로 전파하지 않습니다.
- 재개 위치는 인과관계와 수정 시각으로 결정합니다. 두 기기에서 동시에 공부한 경우 한 재개 위치를 선택하지만 양쪽 완료 내역은 유지합니다.
- 같은 기억노트를 동시에 수정하면 다른 수정본도 별도 노트로 보존합니다. 나중에 이루어진 정상 수정·삭제는 전달합니다.
- 원격 진도를 적용하기 전 변경될 로컬 파일은 `nas-sync-backup`에 보존합니다. 손상되었거나 다른 프로필인 원격 자료는 적용하지 않습니다.
- NAS 폴더 마커가 없으면 연결되지 않은 폴더에 임의로 대체 저장하지 않습니다.

**연결할 모든 기기에 동기화 기능이 들어간 버전이 필요합니다.** Android의 기존 진도는 PC 공통 형식으로 변환하며, 기존 완료 기록과 다른 기기에서 받은 항목은 삭제하지 않습니다. Python·Conda·Jupyter의 문제별 통과와 소단계 위치, Linux·Docker·ROS 2의 단원 완료·복습 완료·설명 소단계 위치를 연결합니다. Android에 편집 화면이 없는 PC 기억노트 등은 보존하여 전달하되 휴대폰에 새 편집 기능을 제공하는 것은 아닙니다.

Android의 받은 진도는 앱 프로세스를 완전히 종료한 뒤 다시 열 때 적용됩니다. 공부 중 원격 위치를 강제로 적용하지 않습니다. 메뉴의 **지금 NAS에 저장**으로 이동 전 전송을 요청할 수 있습니다. 종료 직전 OS가 앱을 강제 종료하면 미전송 진도는 다음 실행 때 전송합니다. 설치 파일 업데이트와 진도 동기화는 별개이며, 문제 내용은 앱 업데이트로 갱신됩니다.

NAS 주소·프로필 ID는 기기별 `nas-sync-config-v1.json`에 저장하며 공개 소스나 배포 기본값에 넣지 않습니다. 새 OS용 실행파일을 배포할 때 개인 연결 설정을 포함하지 마세요.
