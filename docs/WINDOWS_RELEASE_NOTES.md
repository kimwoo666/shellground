Windows 설치 및 실행 호환성 수정판입니다. Linux/Android 다운로드는 기존 4.7.4 배포를 사용합니다.

- 설치할 때 NSIS의 System.dll을 .NET 어셈블리로 잘못 읽던 오류 수정.
- 번들 QEMU 11의 재연결 옵션으로 변경하여 Windows Linux VM 부팅 복구.
- 한글·공백 설치 폴더와 임시 폴더에서도 QEMU BIOS·실습 디스크를 읽도록 상대 경로 사용.
- CPU 사용량을 제한한 환경의 첫 ROS 2 실행에서 실제 DDS 관찰값을 기다린 뒤 실습 시작.
- Windows 한글 파이프, 전체 Python 검사, QEMU 경로 검증 오류 수정.
- Windows 네이티브 빌드, 고정된 의존성, SHA-256 파일 검증 및 버전별 설치 폴더.

`Shellground-Windows-Setup.exe` 하나를 실행하면 됩니다. 설치 중 프로그램과 실습 자료를 자동으로 내려받습니다. 별도 Python, Docker, ROS 2, Conda 또는 WSL 설치는 필요하지 않습니다.

처음 설치할 때 인터넷 연결과 약 9GB의 여유 공간이 필요합니다. 기존 검증된 실습 디스크는 그대로 사용합니다. 파일은 서명되지 않은 개발 배포본입니다.

실제 Windows 검증 범위와 제한은 저장소의 Windows 검증 기록을 참고하세요. 다른 PC의 장치·그래픽 드라이버 및 WHPX 없는 소프트웨어 실행 성능까지 동일하다고 보증하는 자료는 아닙니다.
