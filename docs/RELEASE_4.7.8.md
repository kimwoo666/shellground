# Shellground 4.7.8

- Linux·Docker·ROS 2 단원 목록을 다시 그릴 때 사용자가 스크롤한 위치를 보존한다. 다른 단원을 선택하면 선택 항목을 가운데로 가져온다.
- 종합 복습 완료 키와 마지막으로 선택한 미완료 복습 키를 NAS 진도에 저장한다. 다른 기기에서 앱을 다시 열면 해당 복습 대기 화면으로 이어진다. 실제 실습 파일과 실행 중인 프로세스는 복원하지 않는다.
- Python scikit-learn 과정에 분류 및 지표, 전처리 파이프라인, 교차 검증과 시간 순서 검증 단원 각 3문제를 추가했다. 기존 완료 키는 유지하고 새 단원은 미완료로 시작한다.
- Windows 설치 후 기존 Shellground 작업표시줄 고정 아이콘을 새 버전 실행 파일로 갱신한다.
- NAS 연결 정보와 개인 진도는 설치 파일에 넣지 않는다. 먼저 쓰던 기기의 진도 동기화 상태가 **NAS 저장 완료**인지 확인한 뒤 다른 기기에서 앱을 완전히 닫고 다시 열어 불러온다.
