# Linux Jupyter 검토판 — 준비 중

소스 버전 4.7.4-dev. 아직 새 실행파일의 최종 검증 전이다. 기존 4.7.3 `dist-linux-pip-review/Shellground`는 덮어쓰지 않았다.

## 이번 변경

- Python 모드 안의 **노트북·Jupyter** 탭. 별도 창이나 웹 브라우저 없이 코드 셀과 설명 셀을 사용한다.
- 실제 basic/data Conda 환경의 Jupyter 커널 선택·재시작·등록. 화면에 선택된 Python 경로를 표시한다. Bash에서 활성화한 환경과 노트북의 선택은 독립적이다.
- 실행 순서와 재현성, 패키지 설치 대상, 문서 저장을 5단원과 종합 복습으로 학습한다. 총18문제이며 기존 Python·Conda 진도를 대신 완료 처리하지 않는다.
- Python 강의 보완4단원: 날짜 인덱스, 월별 평균과 유효 관측 수, Series 막대/원그래프, concat의 원래 행 라벨. Python95단원285문제, 개념카드36개/퀴즈61개다.
- ROS 활용1은 기존 예시와 같은 문제를 반복하지 않고 선행 기능 조합16개와 낡은 보고서 수정4개로 바꿨다. 원래 번호·목표·활용2 인계·복습 범위는 유지했다. 기록 예시에서 발행자 없는 토픽 구독을 먼저 기다리던 순서는 수정했다. 관련 실제 채점 보완은 검증 중이다.
- 실행 순서·설치/import 퀴즈의 관련 실습 목록에서 실제 Jupyter 과정으로 이동할 수 있다. 기존 Python/Conda 목적지도 유지하며, 취소하면 입력과 선택 화면을 보존한다. 연결 클릭만으로 실습을 실행하거나 완료 처리하지 않는다.

## 사용 방법

1. Python·데이터 → 노트북·Jupyter를 선택한다.
2. 설명을 읽고 실습 열기(F4)로 앱 전용 환경을 준비한다. 첫 준비는 즉시 끝나지 않는다.
3. 코드 셀은 Shift+Enter로 실행한다. 환경 등록·패키지 작업은 Bash 탭에서 수행한다.
4. F5로 채점한다. 틀렸다면 문제·설명 탭으로 돌아가 같은 문서와 커널에서 수정한다. 커널 재시작은 코드와 변수를 구분하여 메모리만 새로 시작한다.
5. F6으로 진행한다. 완료 여부와 소단계 위치는 자동 저장한다. 입력 코드·임시 파일·커널 변수는 앱 종료 후 복원되지 않는다. 문서 저장 버튼은 실습 VM 안의 파일 저장이다.

## 완료를 확인한 범위

- Jupyter 최신 소스:18문제·추가8종 PASS(220.35초), VM/임시 디스크 정리 확인. 순서 문제의 숨은 환경 제한, 후행 출력 셀로 반복 검사를 피하는 경우, 실제 커널 재생성 동등 풀이까지 포함한다. 최신 UI 재검사와 새 실행파일 인수는 별도로 한다.
- Python 보완의 실제 라이브러리 오답/동등 풀이26검사 PASS. 새 실행파일에서도 전체285문제를 다시 검사한다.
- Linux/Docker 기존 과정225문제+15복습 PASS. 뒤이은 ROS 채점 수정까지 포함한 새 배포 인수는 아직 진행 중이다.

**등록된 문제의 전체 통과와 PDF에 언급된 모든 명령·옵션의 학습 구현 완료는 다르다.** 고급 Linux/Docker 미구현 범위와 하드웨어 필요 항목은 별도 범위 감사에서 계속 구분한다. 다른 OS 실행 성공이나 전체 프로젝트 완료를 주장하지 않는다.

추가 대조 결과는 [Linux/Docker 범위 감사](python_teaching/LINUX_DOCKER_SCOPE_AUDIT.md)에 있다. passwd/su, 프로세스 조사, APT 복구, 시스템·네트워크·시간, Docker attach·실제 포트 통신·자원 관찰 등이 독립 평가로 남아 있다. 이를 단원 수나 현재 문제 PASS로 대신 완료 표시하지 않는다.

전체 분야의 등록 수와 강의 공백의 구분은 [현재 학습 범위](CURRENT_COVERAGE.md)에 정리했다.

## 배포 및 안전

새 산출물은 기존 배포를 보존하는 `dist-linux-notebook-review`에 만들 예정이다. 실행파일과 같은 폴더의 runtime을 함께 사용한다. 개발 PC에서는 읽기 전용 OS 이미지의 하드링크로 디스크 중복을 줄이지만, 학습 데이터는 항상 별도 임시 디스크에 기록한다.

호스트의 개인 Python·Conda·Jupyter 설정을 바꾸지 않는다. 커널은 앱 전용 VM 내부에서 실행한다. 공식 wheel의 버전·URL·SHA256은 `notebook_teaching/assets-linux-x86_64.json`에 기록하며 학습 실행 중 인터넷 다운로드는 하지 않는다.

사용자 지시에 따라 Linux 검증을 먼저 마무리한 뒤 Windows → Android → macOS 순서로 진행한다. 미검증 플랫폼은 완료로 표시하지 않는다.
