# Bash 실행·상태·인자 학습

Linux 71–75번과 종합 복습. 기존 1–70번과 완료 키를 보존한다. 아직 새 실행파일에 포함하기 전이다. 가상 Linux 명령 엔진을 수정하지 않고, 전용 실제 Linux의 Bash와 파일·현재 셸 상태를 평가한다.

| 단원 | 새 개념 | 활용의 차이 |
| --- | --- | --- |
| 71 | type·whereis와 PATH | 두 설치 경로를 보존하며 선택 우선순위 복구 / 다른 폴더로 이동해도 같은 명령 선택 |
| 72 | source와 자식 셸 | 낡은 프로젝트 보고서 백업 후 현재 셸 복구 / 자식 값은 기록하되 부모 값은 유지 |
| 73 | $0·$#·"$@"·"$*" | 인자를 합쳐 버리는 결함 수정 / 기존 초안을 보존하며 재사용할 도구 작성 |
| 74 | if·인자 개수·오류 상태 | 검증 없이 파일을 쓰는 결함 수정 / 공백 경로 문서 인계와 기존 초안 백업 |
| 75 | noclobber·대문자 -C | 기존 파일을 덮어쓰는 결함 수정 / 원본 초안 보존과 안전한 새 파일 작성 |

설명과 함께 실행하는 2–3개 소단계를 제공한다. bash -C는 단순한 스크립트 실행 허가가 아니며 소문자 -c와 다르다. 반복되는 활용도 실제 준비된 결함·보존 조건·부모/자식 상태·작업 위치를 바꿨으며 파일 이름만 바꾸지 않았다. 스크립트 작성 시 nano를 사용해도 되고 예시 printf를 사용해도 된다.

복습은 현재 셸에 설정을 적용하고, 그 작업 폴더에 안전한 파일 생성 도구를 작성하는 조합이다. 기존 파일에는 표준 오류와 실패 상태를 내고 원본을 보존하는 것을 목표에 명시한다. 인자 개수 단원의 정상 입력은 원본과 대상이 같은 실제 파일이 아니라고 명시하여 잘못된 자기 덮어쓰기를 정답으로 유도하지 않는다.

## 실제 채점

PATH는 현재 셸의 내보낸 값을 읽는다. 보고서만 맞고 현재 환경이 틀리면 실패한다. 동일한 경로의 `.`·끝 `/`·심볼릭 링크 해석을 정규화한다. source 과정도 실제 현재 환경값과 작업 폴더를 검사한다.

작성한 스크립트는 다른 인자·공백·빈 문자열·와일드카드 문자 및 별도 파일 내용으로 실제 실행한다. 저장된 정답 보고서만으로 잘못된 프로그램을 통과시키지 않는다. 호출을 `arguments.sh`, `./arguments.sh`, 절대경로로 바꾸어도 유효한 보고서를 허용한다. 같은 보존 계약을 만족하는 다른 방어 구문도 허용하며 풀이 문자열을 강제하지 않는다.

제출 스크립트는 VM 안의 learner(UID/GID1100)로 실행하고 root로 실행하지 않는다. 1회 실행은 3초, 파일 출력 1MB, 메모리 주소 공간 256MiB, CPU·프로세스 수 제한을 둔다. 종료 시 해당 실행의 자식 프로세스 그룹도 정리한다. 이는 짧은 학습 스크립트의 자원 제한이며 임의 외부 코드에 대한 보안 보장을 뜻하지 않는다. 실행 후에 원본 보존을 검사하여 검사 도중의 부작용도 확인한다.

새 셸 평가 목록은 보존 파일들을 한 항목으로 묶어 최대 7항목으로 표시한다. 보존 실패 시 실제로 변경된 파일 이름들을 그 항목에 표시한다.
