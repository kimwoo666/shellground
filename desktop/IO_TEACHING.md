목표에 없는 정렬은 강제하지 않는다. tree의 ASCII/Unicode·항목 순서·합계 유무·시작 표제 `.`을 허용하며 이름·계층·줄 경계·중복은 확인한다. 준비 파일·폴더 권한/소유권·시스템 원본을 보존한다. 작성 스크립트는 learner 권한과 기존 실행 제한으로 공백 경로·빈 폴더에 직접 실행한다. 활용2는 다른 현재 폴더에서도 실행하므로 보고서만 맞고 도구가 시작 폴더에 묶이면 실패한다. 자작 Linux 엔진은 변경하지 않았다.

more 과제의 채점은 찾은 값·원본 보존·셸 복귀를 확인하며 다른 유효한 조회 방법도 허용한다. 따라서 파일 결과만으로 특정 키 조작을 증명했다고 표시하지 않는다. 인수 검사에서는 실제 PTY에서 cat 입력/Ctrl+D, more의 Space·Enter·검색·q와 전경 프로세스를 별도로 확인했다. 복습 본문6항목에 공통 미복귀 항목을 더해도 최대7항목이다.
