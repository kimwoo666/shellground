# Linux 검토판 4.7.2-dev — Miniconda 설치 실습

2026-09-17 Linux 검토판 빌드와 실행 검사를 완료했습니다. **새 Miniconda 설치 실습을 검토할 수 있는 후보이며, 전체 프로젝트·모든 학습 범위·다른 OS 지원의 완료판은 아닙니다.** 기존 `dist-python/Shellground-unified`에는 이번 설치 실습이 들어 있지 않습니다.

실행파일: `dist-linux-review/Shellground` (`--version`: `4.7.2-dev`, 167,570,208바이트, 실행 권한 포함).

SHA-256: `0fd96f6498347c93f9a776d283bccb3a0ab6dab91059530b32a4b26e73aee06b`.

프로젝트 루트의 `Shellground-Linux-Review.desktop`은 이 파일의 Conda 화면을 엽니다. 기존 `Shellground.desktop`은 이전 단일 창 수정판을 계속 가리킵니다. 검토용 바로가기만 추가했으며 사용자 홈의 설치 바로가기는 변경하지 않았습니다.

## 실행과 보존

새 검토판은 `dist-linux-review/Shellground`와 같은 폴더의 `runtime`을 한 묶음으로 사용합니다. 실행파일만 다른 폴더로 옮기면 실제 실습 환경을 찾을 수 없습니다. Python·Conda를 개인 PC에 따로 설치할 필요가 없고 호스트 Docker나 WSL도 사용하지 않습니다. 실제 Linux/Conda 실습에는 접근 가능한 KVM이 필요합니다. 사용할 수 없을 때 고부하 소프트웨어 에뮬레이션으로 자동 전환하지 않습니다.

현재 검토 폴더는 실제 Linux 환경을 포함해 약16GiB입니다. 이 크기는 실행 중 메모리 사용량이 아닙니다. 먼저 현재 위치에서 실행해 검토하세요. 이 Linux x86_64 개발 컴퓨터에서 검사한 결과이며 다른 배포판·CPU 아키텍처의 실행 성공을 대신하지 않습니다.

기존 실행파일·런타임·학습 완료 기록은 덮어쓰지 않습니다. 단, 실제로 학습하면 같은 사용자의 기존 진도에 새 완료·소단계 기록이 저장됩니다. 동시에 여러 버전을 실행하지 마세요.

## 이번에 확인할 부분

1. 상단 **Conda · 환경 관리 → 설치 준비·실습 → 설명 보며 실습(F4)**을 엽니다. Linux·Python·Conda는 계속 같은 창에서 전환됩니다.
2. Anaconda/Miniconda/Conda 구분 → 공식 설치 파일과 새 경로 → 설치 옵션 → 새 Python 확인, 네 소단계를 읽으며 직접 실행합니다. 「설치 파일·라이선스」에서 출처·해시·원문 약관을 볼 수 있습니다. 파일을 읽거나 창을 닫는 것만으로 설치하거나 동의하지 않습니다.
3. 설치 평가는 **새 경로의 실제 Conda/Python 실행 결과와 기존 환경 보존**을 확인합니다. 정답 명령 문자열이나 성공 문구만으로 통과시키지 않습니다.
4. 채점에 실패해도 같은 터미널에서 계속 수정합니다. 「문제·설명」 탭이나 「설치 설명으로 돌아가기」를 눌러도 같은 설치 실습을 유지합니다.
5. 종료 후 다시 열면 읽던 소단계와 설치 완료 표시가 남는지 확인합니다. 입력 명령·임시 설치·실습 파일까지 복원하는 것은 아닙니다. **다시 시작(F2)**은 설치 경로를 새로 배정하며 기존 경로를 덮어쓰지 않습니다.
6. 설치 실습 도중 Python 탭으로 이동한 후 창을 닫아도 숨겨진 Conda 실습 환경이 함께 종료되어야 합니다.

## 검증 범위와 남은 작업

- 검토판 목표: 기존 Conda 15단원·3복습·54문제·18학습 시퀀스를 유지하면서 별도 설치 실습을 추가합니다. 기존 단원 번호는 바꾸지 않습니다.
- 설치 실습 완료는 일반 활용 문제 진도와 별도로 저장합니다. 새 설치 실습을 통과했다고 기존 단원 전체를 완료 처리하지 않습니다.
- Linux 소스·전용 guest의 설치/오답 검사와 배포 실행파일 검사는 구분합니다. 아래는 각각 직접 확인한 범위입니다.
- 실제 `pip` 설치·제거 실습과 다른 Linux 필수 범위 보완은 별도 후속 작업입니다. 이번 검토판만으로 전체 목표를 완료했다고 하지 않습니다.
- Windows·Android·macOS용 새 포팅은 하지 않았습니다. **이 Linux 결과물을 사용자가 검토하고 명시적으로 승인한 범위만 이후 포팅합니다.**

## 개발자용 검사

`Shellground --self-test-conda-setup`은 임시 진도와 별도 폐기 가능한 VM에서 네이티브 설치 UI·실제 설치·실패 후 재채점·소단계 복원·숨은 VM 종료를 검사합니다. 학습자 진도를 변경하지 않습니다. `--capture-dir 경로`를 추가하면 검사용 화면을 저장합니다. 검사에 공식 설치 파일이 포함된 검증 런타임이 필요합니다.

Conda 포함 빌드는 전체 과정·학습·설치의 소스 검증 보고서를 먼저 확인한 뒤, 새 실행파일에서 Python 전체 문제·단축키/한 창·일반 Conda 실습·새 설치 실습을 직렬로 검사합니다. 이 검사를 통과하더라도 타 OS 검증이나 사용자 승인을 대신하지 않습니다.
