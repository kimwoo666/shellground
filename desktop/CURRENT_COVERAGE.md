## Python 강의의 남은 범위 검증

기존 다섯 PDF의 대조 결과에서 실제 행동 공백이었던 Jupyter 커널 조작을 별도 과정으로 연결했다. `.dt` 날짜 열만으로 날짜 인덱스까지 학습한 것으로 세지 않았고, 월별 평균과 유효 개수의 결합 및 원래 행 라벨 보존 사례를 추가했다. 보충한 Series 그림은 실제 차트 객체의 범주·값·배치를 확인한다.

원 퀴즈의 자유서술 확장 과제와 연결 실습은 동일한 과제가 아니다. 관련 실습을 통과해도 원 확장 과제를 자동 완료 처리하지 않는다. 카드/선택 퀴즈만 있는 데이터·정보, 3V, 과학 패러다임, 작은 표본 판단, 클라우드 세션 보존의 실행형 서술 채점기를 구현했다고 표시하지 않는다. TensorFlow 모델 학습 전체도 이 강의 범위 구현에 포함했다고 주장하지 않는다.

상세 근거: [Python·Jupyter 감사](python_teaching/JUPYTER_AND_COVERAGE_AUDIT.md), [강의 대조 및 퀴즈 설계](python_teaching/quiz_blueprint.md).

## 발견된 기존 Linux·Docker 누락

대화형 수명·이미지 압축 인계·선별 정리는 [Docker16–20](DOCKER_SESSIONS_TEACHING.md),실제 공개 포트·자원 관찰·최소 권한 스크립트는 [Docker21–25](DOCKER_RUNTIME_TEACHING.md)로 추가 검증했다. ROS 키 조작 보충까지 현재138단원·27복습 총441사례는 새9+검토 재사용432의 증분 게이트를 통과했다. 원432 및 이전 보고서는 보존했다. 이는 새 실행파일 인수나 PDF의 모든 하드웨어 기능 완료를 대신하지 않는다.

입력 종료·페이지 탐색·계층·직접 실행은 [입출력 과정](IO_TEACHING.md)의 새16문제·오답/대안6묶음으로, 시스템·네트워크·시각 조사는 [시스템 과정](SYSTEM_TEACHING.md)의 새16문제·오답/대안8묶음으로 보완했다. 다음 문단의 해당 누락 판정보다 이 기록이 우선한다. RTC 조회 실패도 그대로 보고하며 RTC/NTP 성공으로 표시하지 않는다.

APT 의존성 복구·설정 보존은 [패키지 과정](APT_TEACHING.md),passwd/su·허용된 sudo 사용은 [인증 과정](AUTH_TEACHING.md),PATH/source·인자/분기·덮어쓰기 보호는 [셸 과정](SHELL_TEACHING.md),프로세스/스레드 조사·작업 제어·시그널은 [프로세스 과정](PROCESS_TEACHING.md)으로 구현하고 실제 증분 검증했다. 장치·GPU·X11·snap·RTC/NTP는 환경 조건·설정/관측·기능 실행의 범위를 분리한다. 실제 GPU 계산/X11 표시/snap 설치를 실행 완료로 표시하지 않는다. [개념 UI](SYSTEM_CONCEPTS.md)는 현재33카드/44문항이다. 개념 정답을 해당 실제 실습 완료로 세지 않는다. 상세 옵션의 최종 대조·새 Linux 배포와 포팅은 남아 있다.

위의 “새 Linux 배포와 포팅은 남아 있다”는 과정 개발 당시 기록이다. 현재 Linux·Windows·Android 실행 묶음은 제작됐으며, Windows PC와 Android 실휴대폰 검증은 남아 있다. 강의 모든 세부 옵션의 최종 대조가 완료됐다는 뜻은 아니다.

이들은 Python/Jupyter 추가나 등록 문제 전수 검사의 성공으로 없어지는 항목이 아니다. 정확한 명령별 현재 구현·누락·환경 조건은 [Linux·Docker 범위 감사](python_teaching/LINUX_DOCKER_SCOPE_AUDIT.md)에 기록했다. 자작 Linux 엔진 확장은 하지 않는다.

## 증거를 읽는 방법

- **등록 문제 전수 검사:** 현재 소스의 모든 등록 ID에 대해 준비 상태가 미완료이고, 실제 참조 풀이 뒤 통과하는지 검사한다. 새 명령 범위가 저절로 추가되는 검사가 아니다.
- **오답·동등 풀이 검사:** 특정 잘못된 상태는 거부하고 다른 유효한 풀이도 허용하는지 별도 검사한다. 무한한 모든 Python 코드를 검증했다는 뜻은 아니다.
- **화면 검사:** 단일 창, 실제 키 입력, 선택 커널, 실패 후 같은 상태 수정, 진도 저장, 숨은 실행 환경 종료를 확인한다.
- **배포 검사:** 새 실행파일에서 다시 검사해야 완료다. 소스 PASS와 이전 실행파일 PASS를 새 배포의 증거로 합치지 않는다.
- **증분 검사:** 이미 통과한 동일 기능은 반복하지 않는다. 새/변경 문제와 직접 영향 범위만 실행하며 기존 보고서의 버전·범위를 보존한다. 배포 검사는 새 파일의 실제 포함·실행·종료를 확인하되 전체 과정 반복과 구분한다.
- **다른 OS:** 해당 OS에서 빌드·실행·채점·저장·종료를 확인하기 전에는 지원 완료가 아니다. 이번 목표는 Linux → Windows → Android이며 macOS는 이후 범위다.
