# Linux pip 검토판 4.7.3-dev — 실행파일 검증 완료

Linux x86_64 검토용 실행파일은 `dist-linux-pip-review/Shellground`입니다. 같은 폴더의 `runtime`을 함께 유지하세요(폴더 전체 약16GiB). 실행파일만 다른 곳으로 복사하면 실제 Linux 실습을 열 수 없습니다. 프로젝트 루트의 `Shellground-Pip-Review.desktop`은 이 버전의 Conda 화면을 엽니다. 사용자 검토·포팅 승인 전이며 전체 프로젝트 완료판은 아닙니다.

기존 `dist-linux-review/Shellground` 4.7.2와 `dist-python/Shellground-unified` 4.7.1은 보존했습니다. 예전 실행파일에는 아래 pip 과정이 없습니다. 새 파일을 실행해도 기존 학습 완료 기록은 그대로 읽으며 강제로 완료·초기화하지 않습니다.

실행파일: 184,044,064바이트, 실행 권한 755. SHA-256: `2e5fdcf539802a257466d6b686a8a41a59e24592876dea8af0bf832b39503735`.

검토 순서는 Conda **16·17단원**의 배우기→예시→활용, Python **개념 퀴즈→관련 실습**입니다. pip의 제거 확인 질문에 `n`을 입력하면 취소되고, 채점에서 미완료가 나와도 같은 터미널에서 계속 고칠 수 있습니다. 예시 하나만 통과했다고 단원 전체를 완료 처리하지 않는지도 확인할 수 있습니다.

## 추가한 학습

Conda 화면의 기존 01–15단원과 세 종합복습은 번호·문제·진도를 유지합니다. 뒤에 두 단원을 추가하여 총17단원·3복습·60문제로 구성합니다.

- 16: 선택한 Python 확인 → `python -m pip`의 의미 → 제공된 공식 wheel과 오프라인 설치 옵션 → 설치 정보와 실제 NumPy 계산 확인.
- 17: 제거 대상·남길 도구 구별 → 실제 확인 질문에 응답 → 정상적인 부재와 손상 오류 구별 → 잘못된 환경·손상된 설치 복구.

각 단원은4소단계와 예시, 서로 다른 활용2문제로 진행합니다. 활용은 파일명만 바꾸는 문제가 아니라 설치 환경 선택·설치 정보 읽기·환경 간 잘못된 설치 정리·고장 난 패키지 복구를 각각 다룹니다. 제공된 Python 진단식은 복사해서 사용해도 되며 암기 대상이 아닙니다. 활용 화면에는 설치·제거 정답 명령을 자동 노출하지 않습니다.

학습 위치와 활용 통과 기록은 기존 Conda 진도 파일에 새 키로 저장합니다. 이전 완료 기록을 초기화하지 않으며, 예시 한 개 통과만으로 단원 전체를 완료 처리하지 않습니다. 입력했던 명령·임시 패키지·실습 파일은 앱 종료 후 복원하지 않습니다.

## 실행과 채점

명령은 앱 전용 Linux의 실제 Bash·Python·pip로 실행합니다. NumPy2.3.5 CPython3.12/Linux x86_64 공식 wheel을 함께 제공하므로 개인 Python 설치나 외부 다운로드를 요구하지 않습니다. 이 고정 버전을 최신 버전이라고 가르치지 않습니다. 다른 CPU·Python 버전용 파일과도 구분해 설명합니다.

채점은 대상 환경의 설치 파일899개·metadata·새 Python의 import와 배열 계산을 함께 확인합니다. 패키지가 설치됐다는 문구나 `pip show` 출력만으로 통과하지 않습니다. 제거는 남은 공유 라이브러리도 확인하며, Python·pip·기존 도구와 보존 대상 환경이 정상인지 별도로 확인합니다. 동등한 명령 순서나 대상 Python의 절대경로를 사용한 풀이도 최종 조건이 맞으면 허용합니다.

오답이면 같은 터미널에서 계속 고칠 수 있습니다. 채점 결과 탭에서 문제 탭으로 돌아가도 실습은 초기화되지 않습니다. 새 파일은 Linux에서 먼저 검토하며 사용자 승인 전에 Windows·Android·macOS 포팅은 진행하지 않습니다.

## 개념에서 관련 실습으로

Python 개념 퀴즈에 **관련 실습** 탭을 추가했습니다. 연습할 내용을 읽고 예시·활용 문제를 선택하면 같은 프로그램 창의 Python 또는 Conda 화면으로 이동합니다. 버튼을 누르는 것만으로 코드를 실행하거나 실습 환경을 만들지 않습니다.

60개 퀴즈 중 55개에 관련 실습이 연결되어 있고, 나머지 5개는 아직 직접 연결된 채점 실습이 없다고 표시합니다. 연결된 문제와 퀴즈의 확장 목표가 완전히 같은 것은 아니므로, 무엇을 연습할 수 있고 무엇은 아직 평가하지 않는지 함께 설명합니다. 퀴즈 정답과 실습 통과 기록도 서로 독립적입니다.

다른 Python 실습으로 바꾸면서 입력·실행 상태를 지워야 하면 확인합니다. 취소하면 작성 중인 코드가 남습니다. Python에서 Conda로 화면만 바꿀 때도 Python 입력과 실행 상태를 유지합니다. 실제 실습 시작은 이동한 화면에서 별도로 선택합니다.
