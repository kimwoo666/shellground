# UI 배치 — A 채택 및 결과 탭

2026-09-16. 사용자가 A 균형형을 선택해 4.2.1-dev부터 기본 적용합니다. 후속 요청에 따라 별도 하단 결과 패널을 없애고 문제와 채점 결과가 같은 공간의 탭을 공유하도록 수정했습니다.

현재 1220×880 비교 창에서 문제와 결과 각각 **968×224px**, 터미널은 **968×298px**입니다. 채점 탭으로 전환해도 터미널 크기와 기록은 변하지 않습니다. 평가 항목 7개가 두 열로 스크롤 없이 보이며 1100×760에서도 확인했습니다. 탭은 수동으로 다시 문제로 전환할 수 있고 실습 상태는 초기화하지 않습니다. F6은 통과 상태일 때 결과 탭에서도 작동합니다.

[채택된 문제 탭](ui-previews/adopted-a-question.png) · [7개 평가 결과 탭](ui-previews/adopted-a-results.png)

이하 표와 이미지는 채택 전 시안 비교 기록입니다. 아래 48px 결과 패널/넓게 보기 방식은 현재 결과 탭으로 대체됐습니다.

## 비교 조건

모두 같은 1220×880 네이티브 창, 같은 문제·출력, 같은 본문 11pt/터미널 12pt입니다. OS 테두리를 제외한 Qt 위젯 크기이며 화면 배율·폰트 환경에 따라 달라질 수 있습니다. 실행 엔진은 만들지 않으며 Linux/VM/시뮬레이터를 기동하지 않습니다. 화면의 출력과 미완료 표시는 비교용 예시입니다. 학습 진도와 기억노트는 건드리지 않습니다.

| 시안 | 문제 영역 (폭×높이 px) | 터미널 화면 (폭×높이 px) | 특징 |
| --- | --- | --- | --- |
| 기존 | 922×140 | 918×222 | 현재 배분과 비교 |
| A 균형형 | 972×236 | 968×269 | 문제와 터미널을 함께 확대 |
| B 터미널 우선 | 972×207 | 968×298 | 명령 입력·출력 기록 공간 우선 |
| C 문제 우선 | 972×278 | 968×227 | 긴 설명·복합 목표 공간 우선 |

세 시안의 사이드바 폭은 220px, 결과 패널 높이는 48px입니다. 상단 반복 안내는 메뉴에서 펼칠 수 있게 했고 새 터미널 버튼은 터미널 탭 옆으로 옮겼습니다. 결과 패널은 스크롤 가능하며 일반 실행에서는 ‘채점 결과 넓게 보기’로 130px까지 펼칠 수 있습니다. 문제/터미널 사이 7px 경계선을 끌어 배분을 직접 조절할 수 있습니다. 시안 선택과 드래그 비율은 저장하지 않습니다.

## 실행

- 실행 파일: `dist/Shellground --layout-preview`.
- 비교 창 상단 ‘배치 비교’에서 기존/A/B/C 전환. 비교 전용이므로 실습 버튼과 명령 입력은 비활성화됩니다.
- 실제 실습으로 확인: `dist/Shellground --mode real --layout a` (b/c도 가능). 이 경우에는 실제 실습/진도 저장이 동작하고 과제 시작 시 앱 전용 Linux가 기동합니다.
- Linux 작업 폴더에는 `Shellground-UI-Review.desktop` 실행 바로가기도 추가했습니다.
- Windows 빌드에서도 동일한 UI 소스를 사용하지만 Windows 실행 파일 검증은 아직 하지 않았습니다.

## 공통 변경

- 상단 ‘리눅스 실전 연습’ 문구 삭제, SHELLGROUND 이름만 유지.
- 리눅스 01–35 / Docker 01–10 / ROS 2 01–20 분야 탭. 번호/5개 단원 복습 표시는 각 분야 기준. 저장용 키는 유지.
- Docker와 ROS 2의 시작은 Linux 전체 완료를 요구하지 않음. ROS 2는 실제 모드 전용.
- 이 분야 랜덤과 전체 분야 올랜덤을 구분. 문제 평가 중 단계 제목/명령어 숨김 유지.
- 실제 모드를 주력으로 안내. 시뮬레이터 신규 확장과 Docker 문제/채점 확장은 이번 시안 검토 후로 보류.

## 확인

로컬 회귀 검사 166개 중 123개 통과, 실제 게스트 등 별도 환경이 필요한 43개는 건너뜀(10.726초). 주제별 번호/진도 복원/독립 시작/랜덤 범위/전환 취소/각 영역 확대/시안 선택/엔진 미생성을 포함합니다. UI 변경을 위해 VM을 실행하지 않았습니다. 렌더 이미지를 직접 확인하고 B 시안에서 ROS 2 탭이 잘리던 폭을 보완했습니다.
